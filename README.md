# LevelUp Life

Balance gaming, series and YouTube with learning (Web Design & App Development), focus and daily good deeds.
Local-first: all data stays on your device.

## Website
Open `web/index.html` in any browser, or upload the `web/` folder to any static host
(GitHub Pages, Netlify, Cloudflare Pages).

## Windows app
Install with `dist/LevelUp-Life-Setup-1.0.0.exe` (per-user install, no admin needed;
adds Desktop + Start Menu shortcuts and an uninstaller in Settings > Apps).

## Develop
```
npm install
npm start          # run the desktop app
npm run dist       # build dist/win-unpacked + installer (needs `makensis`)
```
